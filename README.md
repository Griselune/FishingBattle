操作方法

・メニューの操作方法：

&nbsp;	「始める」

&nbsp;	【サーバーを立ちたいか、一人で遊びたい時】

&nbsp;	→　名前を入力してから「ゲームホスト」(部屋を作る画面に移動する)　

&nbsp;	→　部屋のパラメータを入力/設定してから「作る」（マッチメイキング画面に移動する）

&nbsp;	→　マッチメイキングで他のプレヤーを待つか好きなタイミングで「準備」ボタンを押してから「始める」（全員が準備済みのみ）

&nbsp;	→　ゲームスタート！

&nbsp;	【クライアントとしてゲームに参加する時のみ（一人プレイ不可）】

&nbsp;	→　名前を入力してから「ゲームに参加」(部屋を見つける画面に移動する)　

&nbsp;	→　参加したい部屋のところに「参加」ボタンを押す（マッチメイキング画面に移動する）

&nbsp;	→	「準備」ボタンを押して、ゲームスタートを待つ（サーバーのホストしか開始出来ない）
